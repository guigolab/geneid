Chapter 4

Running geneid

Input format, the basic command, the full command-line reference, and the output formats.

Input sequence (FASTA)

geneid reads one or more DNA sequences in FASTA format from a file named on the command line. A record is a header line beginning with > followed by the sequence; line width is free.

>chr21
CCTATCAGCTAGCATCGATCGCATCGATTGCACAGCTAGCTAGCTACGTACG
TCGTACGATCGATCGTAGCATCACGATCAGCATCTAGCACATCACACAGCAT
...

A file may hold several records (multi-FASTA); each is predicted independently. External evidence for a multi-FASTA run must name the matching sequence in column 1 and be sorted by start position within each.

Soft-masking is ignored geneid treats lower-case bases as ordinary sequence; only N is masked. To exclude repeats, hard-mask them to N in the FASTA rather than relying on lower-case soft-masking.

Basic usage

geneid needs the sequence and a species parameter file (see chapter 8). Predictions go to standard output:

$ bin/geneid -P param/human3iso.param samples/example1.fa

The parameter file can be given three ways: with -P <file>; through the GENEID environment variable holding its path; or, if neither is set, from a file named param.default beside the binary. Parameter files are broadly reusable within a phylogenetic group (the human file works across vertebrates).

Command-line reference

Run geneid -h for the terse list. The options below are grouped by purpose; flags marked htslib require a build with BAM support (chapter 3).

General

FlagMeaning
-P <file>Parameter file (else GENEID env var, else param.default).
-p <prefix>Prefix added to predicted gene / protein / CDS names.
-j <coord>, -k <coord>Restrict prediction to the window [begin, end] (1-based).
-vVerbose: progress and diagnostic messages on stderr.
-BReport the memory required for the given sequence, then exit.
-hShow the option list and exit.

Prediction engine

FlagMeaning
(default)Predict on both strands and assemble genes.
-W / -CPredict only the forward (Watson) / reverse (Crick) strand.
-oSignal and exon prediction only — do not assemble genes.
-O <file>Assemble genes only, from exons supplied in a file (chapter 5).
-FForce the prediction of one complete gene structure.
-ZSwitch on open-reading-frame searching.
-UAllow U12 (minor-spliceosome) introns (needs U12 profiles in the parameter file).
-rUse recursive splicing.
-E <n>Add n to the exon-weight parameter (raise/lower how readily exons are kept).

External evidence

Summarised here; see chapters 5–7 for detail.

FlagMeaning
-R <file>Annotations that guide/force predictions: GFF, bigBed, or htslib a BAM whose spliced-read junctions become intron evidence.
-S <file>Signal that scores exons: protein-HSP GFF, bigWig coverage (plus.bw,minus.bw or cov.bw), or htslib a BAM (reads.bam).
-Y <bam[,bam,…]>htslib One or more indexed BAMs used as both -R junctions and -S coverage.
-y <rf|fr|none>Library strandedness for BAM coverage (rf = dUTP/reverse; default none).
-uPredict UTRs (uses the -S/-Y coverage to place UTR ends).
-L <k> / -Q <w>Enable expression log-likelihood-ratio scoring and set its weight (chapter 7).
-K <n> / -I <n>Multi-library agreement, and junction read-support floor (chapter 7).
-N <M>Millions of reads mapped, for the rpkm report (auto-estimated from a BAM).
-V <n>Add n to the score of evidence exons.
-JAnnotation-scoring mode: score and U2/U12-type the splice sites of forced exons (report only).

Choosing what to output

By default geneid prints assembled genes. These flags add or restrict the reported elements and sequences.

FlagOutputs
-b -d -a -eBest start codons / donor sites / acceptor sites / stop codons.
-f -i -t -sBest first / internal / terminal exons, and single-gene exons.
-x -n -zAll predicted exons / introns / open reading frames.
-T -D -AGenomic sequence of exons / of CDS / translated protein, for predicted genes.

Output formats

FlagFormat
(default)geneid native tabular format.
-GGFF2.
-3GFF3 (recommended for downstream tools).
-XExtended format (adds per-signal detail).
-M / -mXML output / print its DTD.

Examples

Ab initio prediction, GFF3, on the bundled example:

$ bin/geneid -3 -P param/human3iso.param samples/example1.fa

Ab initio with translated proteins, on one strand and one window:

$ bin/geneid -3 -A -W -j 1 -k 200000 -P param/human3iso.param genome.fa

RNA‑seq-guided, from an indexed BAM, with UTRs and expression scoring (htslib build; see chapter 7):

$ bin/geneid -3U -u -y rf -L 50 -Q 0.0007 -Y aligned.bam \
             -P param/human.rnaseq.param genome.fa
