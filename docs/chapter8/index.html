Chapter 8

The parameter file

Everything species-specific lives here: the statistical model that scores signals and exons, and the gene model that chains them.

geneid is data-driven. A parameter file describes the probabilistic model the predictions are based on, plus the gene model at the end. The param/ directory ships files for several species (human, Drosophila, plasmodium, dictyostelium, wheat, and more); one file is broadly reusable within a phylogenetic group.

Don't hand-write these Parameter files are trained from annotated sequence, not edited by hand. Use the geneid-train workflow (see the Wiki) to fit and emit a new one. This chapter describes the file so you can read and lightly tune it.

Overall structure

A parameter file has three top-level parts:

  1. NO_SCORE — the value given to exon positions with no homology support (chapter 7). Zero by default; raise it to favour homology-supported predictions.
  2. Isochores — one model per G+C band, so scoring adapts to local base composition.
  3. The gene model — the rules for chaining elements.
# 0. Non-homology penalty
NO_SCORE  0

# 1. Isochore-dependent models (by G+C %)
number_of_isochores 3
boundaries_of_isochore  0 40      # isochore 1
  ...
boundaries_of_isochore 40 70      # isochore 2
  ...
boundaries_of_isochore 70 100     # isochore 3
  ...

# 2. Gene-assembling rules (the gene model)
  ...

Inside one isochore

Each isochore block holds four things:

  1. exon-filtering cutoffs and scoring factors;
  2. signal profiles (position weight arrays);
  3. the Markov coding-potential model;
  4. the maximum number of donors kept per acceptor.

Exon cutoffs and factors

Four values per line, one for each exon type (First, Internal, Terminal, Single). The factors set how the final exon score combines its parts:

Total_score_cutoff          -15 -15 -15 -15   # drop exons below this
Coding_potential_score_cutoff -10 -15 -15 -15   # drop weak coding potential
Site_factor                 0.6 0.6 0.6 0.6    # weight of the splice/site scores
Exon_factor                 0.1 0.1 0.1 0.1    # weight of the coding-potential score
HSP_factor                  0.04 0.04 0.04 0.04 # weight of the homology / coverage score
Exon_weights               -5.5 -5.5 -5.5 -5.4 # constant added to surviving exons

The final exon score is Site_factor·sites + Exon_factor·coding + HSP_factor·evidence, plus Exon_weights (a negative bias that discourages spuriously long, many-exon genes under the additive assembly).

Signal profiles (position weight arrays)

Each signal — start, stop, acceptor, donor — is a PWA: a matrix indexed by (oligonucleotide, position) of log-likelihood ratios between a model of true sites and one of false sites. Four header numbers define it:

HeaderMeaning
lengthsize of the scanned window
offsetdistance to the core element (e.g. the AG / ATG)
cutoffscore below which candidate sites are discarded
orderMarkov order (oligonucleotide length used to score each position)
Acceptor_profile  7 4 -7 1
# order-1 transition scores, per position and dinucleotide
1 AA 0.489398
1 AC 0.559547
1 AG -1.62606
  ...

Optional profiles refine acceptors and enable minor-class splicing: Branch_point_profile and Poly_Pyrimidine_Tract_profile, and the U12 donor and acceptor profiles that -U activates (for the GT–AG and AT–AC subtypes). A Branch_point_score_weight scales how much the branch score contributes.

Coding-potential (Markov) model

Protein-coding potential is measured with a Markov model, usually order 5. Two matrices: initial scores the first oligonucleotide of an exon; transition scores each subsequent position, per codon position, as the log-ratio of the oligonucleotide's probability in real vs. intronic sequence.

Markov_oligo_logs_file
Markov_model_order 5
Markov_initial_probability_matrix
  AAAAA 0 0 -0.85727
  ...
Markov_transition_probability_matrix
  AAAAAA 0 0 -1.10797
  ...

The gene model

The gene model lists the rules for chaining predicted elements. Each rule gives the element types that may connect, in order, and the allowed distance range. Infinity removes an upper bound; block preserves grouped exons (an annotated gene) without interleaving ab initio predictions.

# Intragenic connections (forward and reverse)
First+:Internal+   Internal+:Terminal+   40:25000
Terminal-:Internal- Internal-:First-     40:25000

# Intergenic connections
Terminal+   First+:Terminal-   500:Infinity
First-      First+:Terminal-   500:Infinity

# What may begin / end a prediction
Begin+  First+:Internal+:Terminal+:Single+   0:Infinity
        First+:Internal+:Terminal+:Single+  End+  0:Infinity

Connections between exon types are sometimes real gene junctions — a Terminal followed by a First joins the end of one gene to the start of the next. -F forces geneid to emit a single complete gene structure. Element types not named in any rule (arriving via -O/-R) are ignored during assembly.

Optional: soft intron-length model

Modern parameter files may include a trained intron-length distribution and a weight, turning the hard maximum-intron distance into a smooth, length-dependent penalty on intron-spanning joins. It is inert unless the weight is set, and is waived for junction-supported introns (chapter 7).
