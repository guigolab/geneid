Chapter 2

Signals, exons and genes

geneid predicts genes hierarchically: signals first, then exons, then the optimal chain of exons.

The engine has three stages. First, signals (splice sites and start/stop codons) are found and scored along the sequence with position weight arrays. Second, exons are built between compatible signals and scored by those sites plus a Markov coding-potential model. Third, the best gene structure is assembled from the exons by dynamic programming, maximising the summed exon score subject to a gene model.

Acceptors can be refined with optional branch-point and poly-pyrimidine-tract profiles. With -U and the right profiles, geneid also models U12 (minor-spliceosome) introns — both GT–AG and AT–AC subtypes — and can type each predicted intron as U2 or U12. All signal profiles live in the parameter file (chapter 8).

Frame and remainder

geneid exons are open reading frames delimited by signals. Two values place each exon in its reading frame:

Frame
the number of nucleotides (0, 1, 2) from the exon's first base to the first base of its first complete codon.
Remainder
the number of nucleotides (0, 1, 2) left after the last complete codon. It is fixed by the exon's length and frame.
Note X denotes an unknown codon in translation — e.g. when a masked base (N) falls inside the codon.

Each exon's score combines its site scores, the coding-potential log-likelihood ratio, and any external evidence, weighted by per-exon-type factors in the parameter file. When RNA‑seq is supplied with -u, geneid additionally builds UTR exons to place untranslated 5′/3′ ends (chapter 7).

Genes

A gene structure is a series of frame-compatible exons chained under the gene model. Two exons are frame compatible when

(frame(second) + remainder(first)) mod 3 == 0

Exons are connected as long as frame compatibility holds and the gene model's succession and distance rules allow it. geneid finds the single highest-scoring assembly in linear time by dynamic programming; the gene model that governs which chains are legal is described in chapter 8.
