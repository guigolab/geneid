Chapter 5

Assembling exons into gene structures

With -O, geneid skips ab initio prediction and assembles a gene structure from exons you supply.

geneid's assembly stage is useful on its own: given a set of scored, predicted exons from any source, it finds the gene structure that maximises the summed exon score under the gene model. Supply the exons in a GFF file and select this mode with -O <file>:

$ bin/geneid -O exons.gff -P param/human3iso.param genome.fa

The file must be sorted by start coordinate (GFF column 4). The scores you provide are what gets maximised, so they should be a meaningful, comparable scale — assembling arbitrary or inconsistent scores is not meaningful.

-O vs -R -O assembles only the supplied elements (no ab initio prediction). -R (chapter 6) instead adds external evidence to geneid's own predictions.

Beyond exons: promoters, poly-A, CpG islands

The input may contain predicted elements of any type, not just coding exons — promoters, repeats, poly-A sites, and so on. Element types are matched by the feature name in GFF column 3, and the same names are used in the gene model to say how they may be chained and at what distances (chapter 8). Elements whose type appears in no gene-model rule are ignored.

Frame for non-coding elements Assigning a reading frame to an intergenic element (a promoter, a CpG island) is meaningless. Give such records a frame of . in GFF column 8: geneid expands each into three (one per frame) and computes remainder consistently, so the frame/remainder machinery is bypassed for them.

Scoring or typing a provided structure (-J)

Add -J to run in annotation-scoring mode: geneid scores the splice sites of the forced exons under the parameter's profiles and classifies each intron as U2 or U12, without changing the assembly. It is a report-only companion to -O:

$ bin/geneid -J -3nU -O annotation.gff -P param/human3isoU12.param genome.fa
