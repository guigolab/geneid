Chapter 6

External annotations (-R)

-R folds external evidence into geneid's own predictions — guiding them, or forcing specific elements into the result.

With -R <file>, the final gene structure is built from both the external records and geneid's ab initio predictions. (Contrast -O, which assembles only the supplied elements.)

Input formats

FormatNotes
GFFtext records; must be sorted by acceptor (start) position.
bigBedthe same records, indexed; queried per genomic fragment.
BAM htslibspliced-read (CIGAR N) junctions become intron evidence; sorted internally.

bigBed and BAM are read with per-fragment range queries, so large evidence sets stream rather than load whole. For BAM junctions, strand comes from the read's XS tag, else the minimap2 ts tag, else the GT–AG/CT–AC splice motif.

Competing vs. forced elements

Whether an element is a hint or a requirement depends on its score (GFF column 6):

Scored elements compete with ab initio predictions to enter the final structure:

chr21   lab_XX   Internal   66255   66323   3.27   +   1

An element with a score of . is forced — it must appear in the output (unless a conflicting forced element is also given):

chr21   lab_XX   Internal   66255   66323   .   +   1

Unknown frame

Set the frame in GFF column 8, or use . when it is unknown. geneid then expands the record into the three possible frames, computing each remainder, and keeps frame/remainder consistency during assembly:

chr21   lab_XX   Internal   66255   66323   3.27   +   .
   → internally becomes the frame-0, frame-1 and frame-2 candidates

Preserving whole genes (the group field)

Use the group field (GFF column 9) to tie the exons of one annotated gene together so they are kept as a block, rather than mixed with ab initio exons. Given this annotation, the gene is preserved intact:

chr21   external   Terminal   21839   22922   18.37   -   1   gene_2
chr21   external   Internal   23679   24029    7.99   -   1   gene_2
chr21   external   First      30732   30775   -1.11   -   0   gene_2

Without a shared group id, geneid may interleave its own predictions between the supplied exons.

One BAM for both roles A single indexed BAM can serve as both -R junctions and -S coverage via -Y — see chapter 7.
