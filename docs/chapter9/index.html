Chapter 9

Source code & architecture

geneid is ANSI C in src/, with one header include/geneid.h. This chapter maps the code to the prediction pipeline.

The authoritative source is on GitHub; browse src/ for the current files. The modules below are grouped by the stage they serve, following the flow of a run.

The pipeline

A run moves through these stages, per genomic fragment for large sequences:

  1. Set-up — parse arguments and the parameter file, read the sequence.
  2. Signals — score sites with the profiles.
  3. Exons — build and score candidate exons.
  4. Evidence — fold in annotations, homology and RNA‑seq.
  5. Assembly — chain exons into the optimal gene structure by dynamic programming.
  6. Output — translate and print.
